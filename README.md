# InFashionAI – AI Fashion Content Platform

## 📌 Project Overview

InFashionAI is a university project developed at Technische Hochschule Ingolstadt (THI) that explores how artificial intelligence can support small fashion businesses in creating professional marketing content.

The project focuses on a concept for an AI-powered platform where fashion retailers can upload product images, provide a short description or prompt, and generate studio-style promotional visuals for their products.

## 🎯 Problem

Small fashion businesses often need professional product photos and marketing materials but may not have access to expensive photography studios, professional models, or dedicated marketing teams.

InFashionAI aims to address this challenge by proposing an accessible AI-based solution for creating promotional fashion content.

## 💡 Proposed Solution

The platform concept allows users to:

- Upload a fashion product image
- Enter a description or creative prompt
- Select or explore different AI models
- Generate promotional fashion visuals
- Manage previous generations through chat history
- Organize product information using a knowledge graph
- Share generated content
